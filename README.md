# 🧠 Deep Learning Projects

This repository contains a collection of **Deep Learning projects** implemented using **Python** and **TensorFlow / Keras**. The projects focus on applying deep learning techniques—particularly **Convolutional Neural Networks (CNNs)**—to real-world **image classification** problems.

The goal of this repository is to demonstrate practical, end-to-end deep learning workflows, from data preprocessing and model design to training, evaluation, and visualization of results.

---

## 📂 Projects Included

### 🔹 Arabic Handwritten Letter Classification

A deep learning project that classifies handwritten Arabic letters using a **Convolutional Neural Network (CNN)**. The project covers the full pipeline, including data preprocessing, CNN architecture design, model training, evaluation, and performance visualization.

**Key concepts:**

* CNN-based image classification
* Arabic handwritten character recognition
* Model evaluation and visualization

---

### 🔹 MNIST Handwritten Digit Classification

This project focuses on classifying handwritten digits (0–9) using the **MNIST dataset**. A CNN model is built and trained to achieve high accuracy, demonstrating the effectiveness of deep learning for image recognition tasks.

**Key concepts:**

* MNIST dataset preprocessing
* CNN architecture (Conv2D, MaxPooling, Dropout, Dense)
* Model evaluation and performance analysis

## 🚀 General Workflow

Across the projects in this repository, the following deep learning workflow is applied:

1. Import required libraries
2. Load and preprocess datasets
3. Design CNN architectures
4. Compile models with suitable optimizers and loss functions
5. Train models with regularization techniques (e.g., Dropout, Early Stopping)
6. Evaluate models on test data
7. Visualize results and performance metrics
